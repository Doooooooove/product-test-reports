# Nameclick 0.2.0: Chrome lookup test

- **What I tried:** After the task was claimed, I used the Chrome Web Store installation of Nameclick (extension ID `hnknkbjoidfdjocmdjjfchiggmgmcojl`, version 0.2.0). I signed in through its normal Google flow, entered `https://github.com/torvalds` in the toolbar search field, and completed the lookup. This was my own selected target, not the installation demo. The lookup occurred on 2026-11-11, approximately 03:05 UTC; this is an approximate capture-time estimate rather than a server timestamp.
- **Actual outcome:** The extension returned a Linus Torvalds result card and the status “Email found”. It displayed “Unverified”, “1 lookup used” and “2 left today”. I did not copy, contact or independently validate the returned address. I switched to Experience before capturing the result so that the contact address would not be published. Reopening the existing result from History was labelled “Free to reopen”.
- **Specific observation:** The distinction between finding an address and verifying it was visible: the result said “Email found”, but the contact section separately said “Unverified”. That distinction matters when deciding whether to use a result. History also made it possible to inspect the same card again without another lookup. One improvement would be to keep the verification state visible when switching to Experience, so it is not confined to the Contact view.
- **Installation evidence:** The browser's extension-details page showed the exact extension ID, version 0.2.0 and Source: Chrome Web Store (localized as “来源 / Chrome 应用商店”). The installation screenshot preserves the browser address bar. Developer mode was already enabled in this Chrome profile; I did not sideload this extension.
- **Limits and privacy:** This is one completed lookup, not a claim of general accuracy. The screenshots are ordinary UI evidence, not cryptographic installation attestations. No subscription or paid lookup was purchased. Unrelated tabs, account details and contact addresses are excluded from the submitted screenshots.
